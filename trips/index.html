Adding a trip
  1. Open the trips spreadsheet and add one row per trip.
  2. Fill in the trip name and the date. A postcode is enough to place the pin.
  3. If there is no postcode, use the coordinate finder above, then paste the numbers into the latitude and longitude columns.
  4. Photos need a direct image link. A link to anything else still works, it just shows as a link rather than a picture.
  5. The map picks up new rows within a few minutes. Press Refresh if it is still showing the old list.
  6. Please keep student names off the sheet. Trip, place, date and group only.
