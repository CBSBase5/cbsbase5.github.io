THE PATTERN FACTORY

Squares, fractions, sequences

Seven machines that press, stretch, squash, pack and grow numbers. Pick any one and have a play.

What this is. A factory floor with seven machines. Each one starts with a tiny explainer, then something to play with, then a few to try.

Any machine, any order, skip whatever is not for you. It saves itself on this device. When you are ready, you can send what you did to Jay.

Who is this?

Optional. Pick your initials and the machines that suit you best get a badge.

The foreman bird says: any machine, any order. A lamp lights up when you have had a go on that machine.

Machine 1

The Square Press

Squares from 1² to 15², stamped out in tiles.

Good place to start
Learn a bit

4² means 4 × 4. You say it “4 squared”.

Lay tiles 4 across and 4 down. That makes a square of 16 tiles.

Have a play

Slide the press

Watch the colours. Each new layer is an L shape that adds the next odd number of tiles: 1, then 3, then 5, then 7...

Try a bit

Stamp the crates

Type the answer for each crate. The press above is there to help any time.

Machine 2

The Big Square Splitter

Square any two digit number by chopping it into tens and ones.

Good place to start
Learn a bit

23 is 20 and 3. Split both sides of the square that way.

You get four rooms: 20 × 20, two lots of 20 × 3, and 3 × 3. Add them up.

400 + 60 + 60 + 9 = 529, so 23² = 529.

Try a bit

Fill the four rooms

Fill each room, then add them. Or jump straight to the total if you can.

The pieces get smaller, there are more of them, and the amount shaded stays exactly the same.

Dividing top and bottom by the same number works too.

Machine 4

The HCF Squasher

Squash fractions down to their simplest form, and say how you know.

Good place to start
Learn a bit

Find a number that goes into the top and the bottom. Divide both by it.

The biggest number that goes into both is the highest common factor (HCF). Squash by that and you are done in one go.

Fully squashed means only 1 goes into both. That is simplest form.

Try a bit

Squash it

Tap a squash number. Any number that goes into both will work. Keep going until it is fully squashed.

Machine 5

The Pizza Boxer

Top heavy fractions into mixed numbers, and back again.

Good place to start
Learn a bit

114 means 11 quarter slices. That is more than a whole pizza, so it is top heavy (improper).

A box holds one whole pizza: 4 quarters. 11 slices fill 2 boxes with 3 slices left.

So 114 = 2 34, a mixed number.

Try a bit

Box them up

Pack the slices into boxes, then write the mixed number. Packing is optional if you can see it already.

Try a bit more

Unbox them

Now the other way. Slice every boxed pizza and count all the slices.

Machine 6

The Sequence Conveyor

Growing tile patterns, term to term rules, and making terms from a rule.

Good place to start
Learn a bit

A sequence is a list of numbers that follows a rule. Each number is a term.

This pattern goes 5, 7, 9. It adds 2 each time. That is the term to term rule.

The orange tiles never change. The teal rows grow by one tile each.

Try a bit

What comes next?

The conveyor brings terms 1, 2 and 3. How many tiles will term 4 have?

Try a bit more

Term maker

Here is a rule. Make the first five terms. In an nth term rule, n is the position: 1 for the first term, 2 for the second, and so on.

Machine 7

The nth Term Dial

Find the nth term, then use it to find any term and check who belongs.

Good place to start
Learn a bit

5, 8, 11, 14 goes up by 3. So start with 3n: the 3 times table.

3n gives 3, 6, 9, 12. Every term is 2 short, so add 2.

The nth term is 3n + 2. Want the 100th term? 3 × 100 + 2 = 302.

Try a bit

Dial it in

Set the two dials so the machine makes the target pattern, then test it.

Try a bit more

Type the rule

No dials this time. Type the nth term. Any way of writing it that works is fine.
