BUILD A COMPUTER

Digital media

An empty case, a tray of parts, and nothing that can be broken by getting it wrong.

What this is. A computer with the lid off. Pick up a part, read what it is for, and put it where it goes. Parts that are not ready yet will not go in, and nothing explodes, because this one is made of pixels.

Four stages, about half an hour if you do all of them. Stop after any stage. It saves itself, so you can come back to a half built machine and carry on.

Stage one

Inside the box

Tap a part in the tray. It will tell you what it does and where it lives, and the place it goes will start pulsing. Tap that place to fit it.
