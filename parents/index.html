      How it works

      Their own space

      Each student has their own space, called an HQ, with English and maths in short sections at their level. It saves as they go.

      The plan for the day

      The home page shows what is on now and next, and each day has its own page, so the plan is never far away.

      Games

      There are plenty of games, many made for the group. In an HQ, a game is earned by having a go at some learning first, so the learning stays front and centre.

      Everything is offered rather than demanded. Students choose the order, can skip a question, ask to see an answer, or stop whenever they need to. Every HQ page has a Done for now button that opens a calm screen.

      This half term the group is exploring one big question: If we could time travel, should we? Each student answers it in their own way, through a project they choose.
