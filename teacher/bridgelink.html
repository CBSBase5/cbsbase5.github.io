The list below already gives you each target's steps on clean lines. To add BridgeLink's own wording, the levels and Done ticks that follow you between devices, the shared memory script needs its newest version:

  1. Open the Base 5 shared memory sheet, then Extensions, then Apps Script.
  2. Paste the newest script over everything in Code.gs (it is in the repo at teacher/sync/base5-sheet.gs.txt), then Save.
  3. Deploy, Manage deployments, the pencil, Version: New version, Deploy. The web address stays the same.
  1. Open the pageIn BridgeLink, the student, then the pillar and level shown on the card.
