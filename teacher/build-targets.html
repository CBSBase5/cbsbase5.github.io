CODES & TARGETS

Staff only

Change a student's code, the staff passphrase, or the target wording. It makes two files to upload, and tells you what to change in the sheet.

1. Open

Signed in to a staff school account listed in the People tab, this opens by itself. Otherwise, the staff passphrase.


2. Codes

Four numbers each. Every code is needed to rebuild, because each student's targets are locked with their own; when you are signed in they come from the People tab. Changing a code does not lose anything a student has ticked.

Staff passphrase

One passphrase for Milestones, this page and the live view. Something long.

3. Target wording

The full set, as editable text. Change the wording if you need to, but keep the shape of it intact. If in doubt, leave it alone.

4. Build and upload

This makes targets-enc.js and b5keys.js. Neither holds a code you can read.

  1. Open the data folder on GitHub, drop in both files and commit. They replace the old ones.
  2. In your Base 5 sheet: put each student's code in the People tab, and the staff passphrase in Settings, so signing in keeps working.
  3. Tell anyone whose code changed.
