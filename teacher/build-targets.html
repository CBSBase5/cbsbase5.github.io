REBUILD TARGETS

Staff only

Change PINs, change the staff passphrase, or edit the target wording, then download a new data file.

1. Open the current file

Enter the current staff passphrase. Nothing can be changed until the existing file is unlocked.


2. Set the PINs

Four digits each. Changing a PIN here does not lose anything a student has already ticked, since ticks are stored separately on the device.

Staff passphrase

Use something long. This one protects every student's targets at once, so it should not be four digits.

3. Target wording

This is the full set, as editable text. Change the wording if you need to, but keep the shape of it intact. If in doubt, leave it alone.

4. Download the new file

This produces targets-enc.js. Upload it to the data folder on GitHub, replacing the old one.
