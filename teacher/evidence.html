Open

One update to switch this on

Evidence needs the newest shared memory script. It takes about five minutes, once.

  1. Open the Base 5 shared memory sheet, then Extensions, then Apps Script.
  2. Paste the newest script over everything in Code.gs (it is in the repo at teacher/sync/base5-sheet.gs.txt), then Save.
  3. Choose setup at the top and press Run. Google asks once more for permission, because the script now saves pictures to your Drive and reads the site's activity list. Press Allow.
  4. Deploy, Manage deployments, the pencil, Version: New version, Deploy. The web address stays the same.
